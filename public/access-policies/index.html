The model

Hierarchical where it helps.
Monotonic where it matters.

One policy reads like a path tree. Separate policies intersect like capability boundaries.

01

Start closed

No matching allow means denied. Unknown future operations stay denied.

default: deny
02

Most specific wins

Inside one policy, child rules can carve out or reopen a subtree.

Deny(path).Allow(child)
03

Policies intersect

A context capability can narrow a global policy. It can never widen one.

global ∩ context
Broad access, sensitive carve-out
ALLOW /spaces/*/**
DENY /private/**

Closed namespace, named capability

Purpose-built authority

Grant the operation, not a vague role.

Reading a known key is not enumerating a collection. Appending a log is not reading it back.

GETEXISTSQUERY INSERTSETUPDATEDELETETRUNCATE
Append-only

Log producer

Allow Insert. No read, update, delete, or query capability follows.

Known-key support

Secret lookup

Allow Get, deny Query. Inspect one known record without enumeration.

Analytics

Query-only tool

Allow Query without point reads or mutations—a foundation for field and predicate constraints.

Raw SQL

Opaque by default

Custom SQL text needs an explicit OpaqueQueryScope. A trusted SQL→DTQL analyzer can narrow it later; incomplete analysis still denies.

Future-safe: Truncate exists in the vocabulary now, before a session method does, so existing policies fail closed.

Portable by construction

YAML for humans. JSON for systems.
Any storage you choose.

The loader accepts an io.Reader, not a filename. Keep policies in Git, object storage, a database, embedded assets, or ordinary files.

extension-trackus.yamlYAML
apiVersion: dalgo.io/access/v1
kind: AccessPolicy
metadata:
  name: extension-trackus
default: deny
scopes:
  - path: /spaces/*/**
    rules:
      - id: outside-extension
        effect: deny
        operations: [readwrite]
    scopes:
      - path: /ext/trackus/**
        rules:
          - id: own-data
            effect: allow
            operations: [readwrite]

One matcher, separate intent

Select audit events without changing access.

Reuse the same paths and operations with independent audit and ignore-audit effects. Avoid recursive logging without inventing a second policy language.

AUDITwrite /users/**
AUDITwrite /transactions/**
IGNOREwrite /auditLog/**

Classification only—your application owns persistence, redaction, delivery, and retention.
