DALgo for TypeScript

@dalgo/core is the browser-neutral TypeScript implementation: hierarchical keys, typed collections, structured queries and transaction-only writes.

Install it from npm with npm install @dalgo/core. The package has no database SDK of its own and does not connect to a database by itself; an adapter does. Source: dal-go/dalgo-js.

TypeScript adapters live in dalgo-http-adapters. Browser-local, browser HTTP and trusted-server adapters have separate requirements. See the Go/TypeScript and runtime matrix for source status and limitations.

Maturity: @dalgo/core is at 0.x, and several adapters are read-only or query-only. Each adapter's README states what it supports; an operation it cannot do fails explicitly.
query.ts TypeScript 
// $ npm install @dalgo/core
import { collection, key } from "@dalgo/core";

interface Item {
  title: string;
  done: boolean;
  rank: number;
}

const spaceKey = key("spaces", spaceId);
const items = collection<Item>("items").in(spaceKey);

const query = items.query()
  .where("done", "==", false)
  .orderBy("rank")
  .limit(25)
  .build();

// Pass query to an adapter updated for @dalgo/core.

Choose a runtime

Browser-local adapters and browser HTTP adapters have different requirements from Node.js/server drivers. Use explicit per-adapter lazy imports. Keep server SDKs and service-account credentials on the server. Review CORS, authorization and runtime conditions in the adapter matrix.
