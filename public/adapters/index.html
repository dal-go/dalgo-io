DALgo / Adapters and runtime support

Adapters and runtime support

Implementation, package publication and runtime are tracked separately. Package publication was not verified by this source audit. Runtime badges describe the source and documented contract; they are not live-service test receipts. Browser HTTP access requires suitable CORS and user-scoped authentication. Node.js and edge execution were not qualified in this audit. A server driver can be exposed through an explicitly implemented HTTP service; that does not make the driver browser-compatible.
