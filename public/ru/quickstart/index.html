03 — Быстрый старт

Быстрый старт

Рабочий пример короче 40 строк.

  1. 1

    Установите основной модуль. Встроенный адаптер dalgo2memory идёт вместе с ним — дополнительных зависимостей для старта не нужно.

  2. 2

    Откройте базу данных. Возвращённый dal.DB — единственный тип, о котором должно знать ваше приложение.

  3. 3

    Опишите запись, задайте её данные и прочитайте обратно по ключу.

  4. 4

    Позже замените dalgo2memory на dalgo2sqlite или dalgo2firestore. Ваши обработчики не меняются.

main.go Go 
// $ go get github.com/dal-go/dalgo

package main

import (
    "context"
    "fmt"

    "github.com/dal-go/dalgo/dal"
    "github.com/dal-go/dalgo/adapters/dalgo2memory"
)

type User struct {
    Name  string `json:"name"`
    Email string `json:"email"`
}

func main() {
    ctx := context.Background()
    db := dalgo2memory.NewDB()

    key := dal.NewKeyWithID("users", "u1")
    user := &User{Name: "Ada Lovelace", Email: "ada@example.com"}
    if err := db.Set(ctx, dal.NewRecordWithData(key, user)); err != nil {
        panic(err)
    }

    var got User
    record := dal.NewRecordWithData(key, &got)
    if err := db.Get(ctx, record); err != nil {
        panic(err)
    }
    if record.Exists() {
        fmt.Println(got.Email)
    }
}

TypeScript · браузер

В браузерном TypeScript-проекте со сборщиком установите ядро и адаптер IndexedDB. Аккаунт базы данных не нужен. Данные хранятся в браузере для этого origin; пример не запускается в Node.js.

npm install @dalgo/core@0.8.1 @dalgo/indexeddb@0.4.1

Добавьте код в браузерную точку входа, откройте приложение и посмотрите консоль:

import { collection } from '@dalgo/core';

// Load the selected adapter. IndexedDB runs in the browser.
const { IndexedDbDatabase } = await import('@dalgo/indexeddb');
const db = new IndexedDbDatabase({ name: 'dalgo-quickstart' });
const todos = collection<{ title: string; done: boolean }>('todos');

await db.runReadwriteTransaction(async (transaction) => {
  await transaction.set(todos.key('first'), { title: 'Try DALgo', done: false });
});

const page = await db.query(todos.query().where('done', '==', false).limit(20).build());
console.log(page);
await db.close();
