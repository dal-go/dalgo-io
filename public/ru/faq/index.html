DALgo: вопросы и ответы

DALgo — библиотека с открытым исходным кодом, слой абстракции базы данных (DAL, database abstraction layer) для Go и TypeScript: один интерфейс для записей, запросов и транзакций и адаптеры для разных баз данных. ORM (object-relational mapper, объектно-реляционное отображение) связывает объекты с реляционными таблицами; SQL (Structured Query Language) — язык запросов реляционных баз данных; CRUD (create, read, update, delete) — четыре базовые операции с записями: создание, чтение, изменение и удаление. Начните со страниц DALgo для Go, DALgo для TypeScript, таблицы адаптеров или статей (англ.).

Что такое DALgo?

DALgo — слой абстракции базы данных для приложений на Go. В README он описан как небольшой единый API для записей, запросов, транзакций, хуков и отображения ключей по схеме, а хранилище остаётся деталью реализации. Реализация на TypeScript, @dalgo/core, живёт в отдельном репозитории. Подробнее: DALgo для Go.

DALgo — это ORM?

DALgo — слой абстракции базы данных, а не полноценная ORM. Руководство GORM называет его ORM-библиотекой для Go; DALgo даёт одни и те же вызовы для записей в SQL и в других хранилищах, например в памяти и в Firestore. В основном модуле есть небольшой пакет orm, который связывает коллекции и поля со ссылками на коллекции и условиями DALgo. Сравнение — в статье DALgo vs GORM (англ.).

Какие базы данных поддерживает DALgo?

В основной модуль входят dalgo2memory (в памяти) и dalgo2fs (файловая система). README перечисляет отдельные модули адаптеров: SQL-движки через dalgo2sql, PostgreSQL, SQLite, MySQL, Microsoft SQL Server, Oracle, Firestore, Datastore, MongoDB, Redis, DynamoDB и другие. Адаптеры поддерживают разные операции; таблица адаптеров показывает их по отдельности.

DALgo — открытый исходный код? Какая лицензия?

Да. Модуль Go — dal-go/dalgo под лицензией MIT. Пакет TypeScript @dalgo/core — dal-go/dalgo-js, тоже под лицензией MIT.

Поддерживает ли DALgo транзакции?

Да. RunReadonlyTransaction выполняет функцию с доступом на чтение, а RunReadwriteTransaction — с доступом и на запись. В типизированных коллекциях чтение принимает сессию чтения, а запись — сессию записи, поэтому записать можно только внутри RunReadwriteTransaction. Подробнее: Интерфейсы.

Как тестировать код без настоящей базы данных?

Используйте dalgo2memory, встроенный адаптер в памяти: dalgo2memory.NewDB() возвращает базу, на которой работает тот же код записей, запросов и транзакций. По README он выполняет многие возможности структурированных запросов целиком, поэтому подходит по умолчанию для модульных тестов. Быстрый старт начинается с него.

Что будет, если адаптер не поддерживает возможность?

Адаптер вернёт dal.ErrNotSupported. DALgo не пытается скрыть все различия баз данных; эта ошибка сохраняет основной API честным. Таблица адаптеров показывает, какие операции поддерживает каждый адаптер.

Как установить DALgo?

Для Go выполните go get github.com/dal-go/dalgo и добавьте модуль адаптера для своей базы данных. Для TypeScript выполните pnpm add @dalgo/core; сам пакет к базе не подключается, поэтому нужен ещё адаптер. Подробнее: Быстрый старт.

Есть ли версия DALgo для TypeScript?

Да. @dalgo/core — реализация на TypeScript, не привязанная к браузеру или серверу: иерархические ключи, типизированные коллекции, структурированные запросы, записи, сессии базы данных и запись только в транзакциях. Первый адаптер — для Firestore, он работает в браузере через модульный Web SDK Firebase. Подробнее: DALgo для TypeScript.

Работает ли DALgo с Firestore?

Да. В Go адаптер dalgo2firestore подключает DALgo к Cloud Firestore. В статье Firestore in Go: CRUD and transactions with DALgo (англ.) документ создаётся, читается, изменяется и удаляется, выполняется транзакция чтения и записи, а те же функции в тестах работают на адаптере в памяти.

Когда DALgo не нужен?

DALgo оправдан, когда один и тот же код предметной области должен работать с несколькими хранилищами, включая тестовую замену. Он не подходит, когда сам язык запросов движка и есть продукт. Случаи перечислены в статье When to use DALgo, and when not to (англ.).

Что такое TugQL?

TugQL — читаемый формат YAML для структурированных запросов DALgo. Его реализация на Go — пакет tugql в основном модуле, он сериализует dal.StructuredQuery. Подробнее: TugQL (англ.).

Кто поддерживает DALgo?

DALgo разрабатывают участники DALgo в организации dal-go на GitHub; как внести вклад, описано в CONTRIBUTING.md. DALgo служит слоем доступа к данным в инструментах разработки DataTug, а сервисы Sneat на Go тоже зависят от этого модуля. Подробнее: Технологии DALgo.
