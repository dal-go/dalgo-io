DALgo / Технологии DALgo

На чём построен DALgo

Технологический стек — это языки, инструменты и инфраструктура, из которых сделан продукт. DALgo — библиотека доступа к данным: общий интерфейс для записей, запросов и транзакций с адаптерами для разных хранилищ.

Этот сайт

Страницы dalgo.io собирает скрипт на Python в статический HTML. Исходники текстов на английском и русском языках находятся в репозитории сайта; опубликованные страницы обслуживает Cloudflare Worker dalgo-io. Для чтения документации браузеру не нужен JavaScript-фреймворк.

Продукт

Go-модуль DALgo и библиотека TypeScript @dalgo/core предоставляют похожие модели данных для разных сред выполнения. У каждого адаптера свои возможности; таблица адаптеров показывает их отдельно. Оба репозитория опубликованы под лицензией MIT: Go и TypeScript.

Наши инструменты здесь

TugQL задаёт читаемое YAML-представление структурированных запросов DALgo; реализация на Go живёт в основном модуле. DataTug использует DALgo как слой доступа к данным при разработке рабочей среды для изучения баз данных. Сервисы Sneat также зависят от Go-модуля DALgo.

Связанные проекты

Откройте язык запросов TugQL или DataTug, чтобы увидеть разные применения общего интерфейса.
