DALgo / Technology behind DALgo

How DALgo is built

A tech stack is the set of languages, tools, and infrastructure used to make a product. DALgo is a data access library: one interface for records, queries, and transactions, with adapters for different stores.

This website

A Python script renders dalgo.io into static HTML from English and Russian source copy. Cloudflare Worker dalgo-io serves the published files. Reading the documentation requires no production JavaScript framework.

The product

The Go module and TypeScript @dalgo/core library offer related data models for different runtimes. Adapters retain their own limits, which the adapter matrix lists individually. Both repositories use the MIT license: Go and TypeScript.

Our tools used here

TugQL gives DALgo structured queries a readable YAML representation; its Go implementation lives in the main module. DataTug uses DALgo as a data access seam while building a database exploration workbench. Sneat Go services also depend on the DALgo module.
